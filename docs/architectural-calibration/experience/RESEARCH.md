# 入廟引導與室內細節 01

## 本輪原創模型

- 文昌帝君、關聖帝君及主龕：依東華三院照片核對面向神龕時左關帝、右文昌；兩尊深色面容，左像垂珠冠及綠袍，右像花飾冠及紅袍。模型保留這些可見差異；臉形、衣褶與繡紋是簡化雕塑，不是實物掃描。
- 紅帷、木龕框、金色邊飾、花瓶、花葉、燈座與果盤：依照片觀察物件種類，位置及數量為配合模型比例的示意。
- 小型配像：照片可見主像前有多尊小像；本轮以四尊示意，未推定身份或準確數量。
- 鐘與鼓：依東華三院廟內草圖，位於右側前部；幾何形制及尺寸待核對。
- 神威普佑：文字與 1879 年御賜、賑災的背景有東華三院文字依據；本輪以簡化黑底金字匾重繪，邊飾、尺寸、安裝高度未實測。
- 兩側神龕：只补框架，未編造缺乏照片依據的包公、城隍造像。鑾輿、執事牌、完整雕刻與題字仍待後續補充。

## 教學及操作

引導為：入廟 → 點懸香／觀察煙 → 分別認識二帝 → 兩個生活情境 → 自由探索。每階段只揭示當前操作，不要求自由書寫；錯答有提示，可重試。學問與信義的生活情境是教學詮釋，不是聲稱只有某位神明代表某種唯一價值。

導覽自動帶動視線；自由探索才開放旋轉。提供返回、重新開始、重看視角及減少動態支援。初中使用者可先觀察，再建立歷史與生活的連結。沒有要求學生進行宗教儀式。

## 2026-09-23 教學定位修正（取代上面的觀察流程）

依使用者最新指示，本段只作到訪前的禮儀及參拜情境演練。移除煙的方向題、辨認主神任務、學問／信義生活題及自由觀察出口。模型及文物細節保留為情境背景，不提前完成現場探究。

現行流程：入門準備 → 遇到參拜者先禮讓 → 自願參拜或安靜等候 → 確認拍攝安排及安全離開。灰色人物及等候圈為教學疊加，不是實際廟內標記。輕聲、不阻塞、不觸碰供品法器、先問拍攝允許為本演練採用的參訪禮儀。

查閱 [東華三院廟宇介紹](https://temples.tungwahcsd.org/twghs-man-mo-temple) 及 [2026 頭炷香活動安排](https://temples.tungwahcsd.org/latest-events/detail?_lang=en&id=2585)。後者說明特定活動有個別香火安排，不能外推為全年規則；公開資料不足以核實統一的香枝數目、左右腳、行禮次數等。本輪不杜撰這些儀式規則，先教學生向廟方確認，依老師與廟方安排安靜行禮。學生不必參拜，兩條選擇皆可完成演練。

## 文化禮儀演練修訂（2026-09-23）

這一輪把泛泛的入廟守則改為可操作的文化次序：示範左腳先跨過門檻、保留善信與神壇之間的空間、自願參拜、先確認香燭安排、向文武二帝稟願、按指定香爐供香，以及離門時跨檻。門檻金色標帶和足印都是教學疊加，不是古蹟復原物件；不以螢幕輸入個人願望。

東華三院的[建築資料](https://www.tungwah.org.hk/heritage/historic-architecture/man-mo-temple/architectural-design/)提供上環文武廟入口及建築背景，但未公布「左腳先入」為必守條文。具體提到左腳入的[上環文武廟旅遊導覽](https://www.hongkong-traveller.com/visiting-man-mo-temple-a-guide-to-its-rituals-and-sacred-etiquette/)屬非廟方資料；[中大教職員會通訊](https://cusa.cuhk.edu.hk/images/data/Newsletter/2012-07.pdf)也記錄「左腳入、右腳出」的通用民俗說法。因此互動將腳步次序標為示範，不給宗教正誤的絕對判定；行動安全、無障礙需要和現場指示優先。

[《就係媒體》報道](https://beinghongkong.com/Offer-God)記述廟方官方社交平台的參拜影片，先準備寶燭、蠟燭置於指定燭台、向文武二帝稟願、大香供於圓形香爐，之後細香及寶牒由現場安排。這是報道對影片的記述，尚未直接核對該影片，因此介面也採「有報道記述」字眼；不把點香支數、繞行方向、節慶安排或燒寶方式寫成全年固定規則。
